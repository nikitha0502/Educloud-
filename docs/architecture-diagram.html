📊 Key Data Flows

1
Registration: User fills form → Browser calls POST /auth/register → Lambda creates Cognito user + DynamoDB profile → Confirmation email sent
2
Login: Credentials → Lambda → Cognito USER_PASSWORD_AUTH → Returns JWT Access Token + ID Token → Token stored in sessionStorage
3
Assignment Creation: Faculty fills form → POST /assignments with Bearer token → API Gateway validates Cognito token → Lambda writes to DynamoDB
4
File Upload: Student selects file → POST /files/upload-url → Lambda generates S3 Pre-signed PUT URL (valid 5 min) → Browser PUTs file directly to S3 (no credentials exposed) → POST /submissions records metadata in DynamoDB
5
File Download: User requests download → POST /files/download-url → Lambda generates S3 Pre-signed GET URL → Browser redirects to signed URL → File served from S3
6
Grading: Faculty opens submission → PUT /submissions/{id}/grade with grade+feedback → Lambda updates DynamoDB submission record → Student sees grade on next dashboard load
